# Fonts

`NotoSansHebrew-Regular.woff2` and `NotoSansHebrew-Bold.woff2` are the Hebrew
fonts of Android 14 (`/system/fonts/NotoSansHebrew-*.ttf`, converted to WOFF2),
so Hebrew text looks and measures exactly like in the Android app.

Noto Sans Hebrew is © Google, licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling it with software.

Latin text uses Roboto from `@fontsource/roboto` (Apache 2.0), the same
vertical metrics as Android's Roboto.
